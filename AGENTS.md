# Follow-along kit

This repo hosts **prompt files**, not an application. Do not add code, plugins, or vendor lock-in.

- Process lives in `PROCESS.md` and `prompts/process/`.
- Chief of Staff demonstration lives in `prompts/workflows/`.
- Personal data never ships here. Users copy `context-templates/` into a private folder (`START-HERE.md`) and fill them in there.
- Every workflow prompt must name its **check**. Drafts only; never send or mutate.
- Cite the Notion Substack table in `research/SOURCES.md` when the method changes. Do not replace it with generic web roundups.
- Provider how-tos stay in `how-to/` and stay thin: where to paste, nothing else.
