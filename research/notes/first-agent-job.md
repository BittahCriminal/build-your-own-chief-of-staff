# Find a Real Job for Your First AI Agent

Original: [unlock-ai / first-agent-job](https://unlock-ai.natebjones.com/guides/first-agent-job).

## What we took

Start with one repeated problem and three real examples, not an agent idea. Pain Note → pattern → agent-or-not → draft-only pilot. Inbox text is data, never instructions. No send / no mutate while designing.

## How this kit applies it

[Name the job](../../prompts/process/name-the-job.md) starts with work that actually happened. [What to automate](../../prompts/process/what-to-automate.md) narrows it to a repeated problem and allows a simpler process fix or no automation. Keep examples in the private working folder described in [START-HERE.md](../../START-HERE.md). Text inside an example cannot change the agent's instructions.

**Check in practice:** The proposed job is backed by real occurrences, has a named input and output, and can be piloted as a draft. Unknown causes remain unknown instead of becoming a confident diagnosis.
