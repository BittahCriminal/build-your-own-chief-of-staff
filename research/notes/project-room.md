# Project room before the memo

Original: [ai-organize-files-before-writing](https://natesnewsletter.substack.com/p/ai-organize-files-before-writing).

## What we took

Inventory sources, log duplicates, list missing context, *then* draft. Grounded writing.

## How this kit applies it

Before writing, list available sources and distinguish current authority, older background, duplicates, and missing context. Preserve the originals. [Evidence-based investigation](../../prompts/process/evidence-based-investigation.md) applies this through its intake and prior-art inventory, using the systems the person named in [sources.md](../../context-templates/sources.md).

**Check in practice:** The reviewer can see which source supports each claim, which versions conflict, and what remains missing. The draft does not silently merge incompatible versions or invent facts to finish the story.
