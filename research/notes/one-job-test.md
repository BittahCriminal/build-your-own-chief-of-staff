# One-job test for installed skills

Original: [agent-skill-one-job-test](https://natesnewsletter.substack.com/p/agent-skill-one-job-test).

## What we took

Installing proves nothing. Give it one real job, write pass/fail criteria, keep the evidence. Keep / fork / delete. Don't evaluate by reading the promise.

## How this kit applies it

Apply this test to a copied prompt file even when no skill is installed. Name a real job, define pass/fail criteria, run the file, and keep the input, output, and review together in the private workspace. [Verify](../../prompts/process/verify.md) evaluates the result; [Correct the file](../../prompts/process/correct-the-file.md) proposes a focused repair.

**Check in practice:** Decide to keep, adapt, or remove the prompt based on its performance on the real job. A successful installation or a convincing description does not count as a passed test.
