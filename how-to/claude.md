# Claude

Works in claude.ai, Claude Desktop, or Claude Code. Same files. Get them first: [START-HERE.md](../START-HERE.md).

1. Start a new chat (or a Project, if you use those).
2. Paste the prompt file into the message.
3. Attach your filled-in context files from the **private** folder, or put those private files in a Project so they load every time. Do not upload the whole kit if it contains nothing extra — one prompt + context is enough.
4. Run. Read the draft. You send.

If you use Claude Code: open the kit folder, paste [`bring-it-home.md`](../prompts/process/bring-it-home.md) once, then point at the markdown files on disk. Still drafts only. Do not grant send / submit / pay tools on the first run.

This kit is not a Claude plugin. The plugin packaging of the same processes is a different repo.
