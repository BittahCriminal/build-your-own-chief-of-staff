# Gemini

No disk required. See [START-HERE.md](../START-HERE.md) path 1.

1. Open Gemini (gemini.google.com) or Gemini in Google Workspace, whichever you already use.
2. Start a new chat. Paste the prompt file (GitHub → the file → **Raw** → copy).
3. Upload your filled-in **private** context files and this run's evidence (Doc, Sheet, or meeting notes).
4. Run. Read the draft. You send.

If Gemini offers to send the email or update the calendar for you, decline. Copy the draft out yourself.
