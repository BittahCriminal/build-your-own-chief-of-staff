# ChatGPT

No disk required. See [START-HERE.md](../START-HERE.md) path 1.

1. Start a new chat (GPT-4.1 / GPT-5 class, whatever you have).
2. Optionally create a GPT or a Project and upload your filled-in **private** context files so you do not re-attach them every time.
3. Paste the prompt file into the message (GitHub → the file → **Raw** → copy).
4. Attach any evidence for this run (last week's tickets, the meeting notes, the calendar export).
5. Run. Read the draft. You send.

Turn off any "take action / send email" connector for these workflows. Drafts only.
