# GitHub Copilot

Get the kit on disk first ([START-HERE.md](../START-HERE.md)). Then:

1. Open the kit folder in VS Code / Visual Studio.
2. Open Copilot Chat (`Ctrl+Shift+I` / `Cmd+Shift+I`).
3. Set the chat to use the current file or `@workspace`.
4. Paste the contents of the prompt file into the chat.
5. Attach or `@`-mention your filled-in context files from the **private** folder (`Documents\chief-of-staff-context`, not `context-templates/`).
6. Run. Read the draft. You send.

Do not enable Copilot to send mail, close issues, or push without you looking.
