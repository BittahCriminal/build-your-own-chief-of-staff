# Cursor

Get the kit on disk first ([START-HERE.md](../START-HERE.md)). Then:

1. File → Open Folder on the **kit** folder.
2. If you do not yet have a private context folder, paste [`prompts/process/bring-it-home.md`](../prompts/process/bring-it-home.md).
3. Open Chat (`Ctrl+L` / `Cmd+L`) or Agent.
4. Paste the contents of the prompt file you want to run.
5. `@`-mention your filled-in context files (`who-i-am.md`, `priorities.md`, `voice.md`, …) from the **private** folder, not from `context-templates/`.
6. Run. Read the draft. You send.

Keep Agent in read-only or ask it to write files you will review. Do not let it send mail, close tickets, or push on the first run.
