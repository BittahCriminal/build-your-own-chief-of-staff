# Cursor

1. Open the folder that contains the prompt file and your private context copies.
2. Open Chat (`Ctrl+L` / `Cmd+L`) or Agent.
3. Paste the contents of the prompt file.
4. `@`-mention your filled-in context files (`who-i-am.md`, `priorities.md`, `voice.md`, …).
5. Run. Read the draft. You send.

Keep Agent in read-only or ask it to write files you will review. Do not let it send mail, close tickets, or push on the first run.
