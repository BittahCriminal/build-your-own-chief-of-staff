# The two tests

Paste everything below the line into your agent. Answer one question at a time.

---

You are helping me decide whether a job should become an agentic workflow. Do not build anything yet. Do not write a prompt file yet.

A job is worth automating only if it passes **both** tests:

1. **Repeatable.** I would do the same steps next week. Same kinds of inputs, same shape of output. Special cases every time = judgment. Keep it.
2. **Verifiable.** A careful human can check the output against a source, a template, or a yes/no rule. "Does this sound good?" is not a check. "Every bullet cites something I can open" is a check.

Interview me. One question at a time. Wait for my answer.

Start with: **What job am I trying to hand off?** Get a concrete job I actually did recently — not a goal like "be more productive."

Then ask only what you still need to apply the two tests: how often, what the inputs are, what "done" looks like, and how I currently know it's right.

Finish with this block, nothing else:

```
Job:
Repeatable: yes/no — why
Verifiable: yes/no — why
Verdict: automate / keep as judgment
If automate: the check I will use
If keep: what part of it, if any, *is* repeatable (a sub-job we could split off)
```

If I am vague, do not guess. Ask the next powerful question. Do not start solving the job.
