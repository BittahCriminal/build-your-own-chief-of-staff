# Meeting prep

## When to use
Before a meeting that matters. Reconstruct who will be there, what is still open with them, and the one decision you need. Not a research dump.

## Inputs
Required: `people.md`, `priorities.md`, `open-loops.md`, `decisions.md`, meeting title, attendees, date/time.
Optional: last recap with this group, a doc the meeting is about. If a source is missing, say so — do not invent the room.

## Steps
1. Read context files first.
2. For each attendee in `people.md`: what they care about, last open loop, last decision involving them.
3. Name the purpose of *this* meeting in one sentence, tied to a priority. If you cannot, say so.
4. List the decisions that must leave the room, and the questions that can wait.
5. Draft a one-page brief. Do not send calendar updates or pre-reads unless I ask.

## Output

```
# Prep — <meeting> — <date>

**Purpose:** <one sentence, tied to a priority or "unclear — ask in the first two minutes">

**Who / what they care about**
- <name> — <from people.md> — open loop: <or none>

**Must leave with**
- Decision: …
- Decision: …

**Can wait**
- …

**Suggested opening (30 seconds)**
- …

**Coverage:** sources used / sources missing
```

One page. No biography of the attendees. No political speculation.

## Check
- Every attendee note cites `people.md`, an open loop, a decision, or a doc I can open.
- "Must leave with" is decisions, not a topic list.
- Nothing about "how the room will land" unless I wrote it in `people.md` myself, dated.
- I still walk in and run the meeting.

## Do not
Invent motives. Skip attendees you cannot identify. Send a pre-read I did not ask for. Treat the invite description as gospel if it contradicts `priorities.md`.
